CSS Box Model Exploration

Content, Padding, Border and Margin

Box Model Layers

Content

Content: The actual text or data inside an element.

Padding: Space between the content and border.

Border: The line surrounding the padding and content.

Margin: Space outside the border that separates elements.

Box Sizing Comparison

content-box

Default box-sizing. Padding and border are added to the declared width.

border-box

Padding and border are included inside the declared width.
