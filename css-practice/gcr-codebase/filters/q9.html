Responsive Design Principles

Core concepts for building responsive websites

Fluid Layouts

Fluid layouts use flexible units such as percentages to allow content to adjust according to the screen size.

.container {
  width: 100%;
  max-width: 1200px;
}

Flexible Media

Flexible media allows images and videos to resize automatically so that they fit within their containers.

img {
  max-width: 100%;
  height: auto;
}

Breakpoints

Breakpoints allow CSS styles to change when the screen reaches a specific width.

@media (max-width: 600px) {
  .box {
    width: 100%;
  }
}
