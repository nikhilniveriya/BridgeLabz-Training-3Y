Responsive Design

Responsive web design allows a website to automatically adapt to different screen sizes and devices.

CSS Grid and Flexbox can be used to create flexible layouts. Media queries allow developers to change the layout at specific breakpoints.

Relative units such as %, rem, vw and the clamp() function help create flexible typography and spacing.

CSS Cheat Sheet

Grid

Used for two-dimensional layouts.

display: grid;

Flexbox

Used for flexible row or column layouts.

display: flex;

Media Query

Changes styles according to screen size.

@media (max-width: 700px)

Typography

Creates flexible and responsive text.

clamp(1rem, 2vw, 2rem)
