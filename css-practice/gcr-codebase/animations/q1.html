CSS Pseudo-Classes

Examples of :hover, :focus, :active and :nth-child()

:hover

Hover Over Me

The :hover pseudo-class applies styles when the mouse pointer is over an element.

:focus

The :focus pseudo-class applies styles when an element receives keyboard or mouse focus.

:active

The :active pseudo-class applies styles while an element is being pressed.
