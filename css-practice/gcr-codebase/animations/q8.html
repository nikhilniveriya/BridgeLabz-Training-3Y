Box-Sizing Comparison

Understanding content-box and border-box

Default: content-box

Content Box

With content-box, the specified width applies only to the content.

Padding and border are added to the total width.

border-box

Border Box

With border-box, the specified width includes content, padding, and border.

This makes sizing easier and more predictable.

What is the Difference?

Suppose both boxes have a width of 300px, padding of 20px, and a 5px border.

In content-box, the padding and border are added outside the 300px width.

In border-box, everything is included inside the 300px width.
